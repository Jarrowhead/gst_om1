# Golden Set

Ground truth for extraction quality measurement. **No fabricated invoices — every file here is a real, anonymized document.**

## Layout

```
extraction/golden_set/
├── README.md                    ← this file
├── ground_truth.schema.json     ← JSON Schema for ground-truth files
├── ground_truth/                ← one JSON per document, keyed by doc_id
│   └── INV-0001.json
├── predictions/                 ← extractor output (one JSON per doc_id)
│   └── INV-0001.json            ← generated by the pipeline, not committed by hand
├── images/                      ← source bill images (git-LFS or MinIO-backed)
│   └── INV-0001.jpg
└── thresholds.json              ← optional gate overrides (defaults in the script)
```

## Sourcing & anonymization rules

1. **Real documents only** — sales invoice, purchase invoice, credit note, debit note, export, RCM, multi-page; at least 50% must be `PHOTO`/`WHATSAPP` (the actual input).
2. **Anonymize before commit:** replace real GSTIN/PAN/names/addresses with **valid-format synthetic identifiers** that pass the mod-36 GSTIN checksum. Keep the real→synthetic mapping out-of-band (never in git).
3. **Annotate by hand** into `ground_truth.schema.json`; double-check the mandatory fields. The annotation is the source of truth the model is measured against.
4. **Never** invent invoices to reach a count. A small real set beats a large fake one.

## Mandatory fields (measured by the harness)

supplier_gstin, buyer_gstin, invoice_no, invoice_date, place_of_supply, is_inter_state, rchrg, inv_typ, taxable_value_paise, total_value_paise, cgst_paise, sgst_paise, igst_paise, cess_paise

## Running the harness

```bash
python scripts/measure_extraction.py \
  --ground-truth extraction/golden_set/ground_truth \
  --predictions extraction/golden_set/predictions
```

See `docs/EXTRACTION_SPEC.md` §4 for the gate thresholds (G1 ≥0.90 precision, G2 ≥0.95 recall, G3 ≥0.99 auto-confirm precision).
